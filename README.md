# How Many Tabs Do You Have Open?

One number, digits only: **47**.

47 open browser tabs — high enough to surprise, believable for a tab
hoarder, and it hints at a life of half-finished research: articles to
read, docs to revisit, videos to watch later. Not a joke number picked
to shock, just the honest count of a browser that never closes.

The program writes exactly `47` (no newline) to `/output/entry.txt`,
validates it is 1–5 digits, and reads it back to verify it byte for byte.
